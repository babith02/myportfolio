           DIRECT PUSH FROM TERMINAL - STEP BY STEP
═══════════════════════════════════════════════════════════════

WHY AUTHENTICATION IS NEEDED:
────────────────────────────────────────────────────────────────
GitHub requires authentication to push code. You need to prove 
you own the "babith02" account before uploading files.


METHOD 1: PERSONAL ACCESS TOKEN (Fastest!)
════════════════════════════════════════════════════════════════

STEP 1: Get Token (One-time setup)
────────────────────────────────────────────────────────────────
1. Open: https://github.com/settings/tokens
2. Click "Generate new token" → "Generate new token (classic)"
3. Fill in:
   Name: Portfolio
   Expiration: 90 days
   Scopes: Check ✅ repo and ✅ workflow
4. Click "Generate token"
5. COPY the token (looks like: ghp_xxxxxxxxxxxxxxxxxxxx)

STEP 2: Run These Commands
────────────────────────────────────────────────────────────────
Copy and paste these ONE BY ONE in your terminal:

git remote add origin https://YOUR_TOKEN_HERE@github.com/babith02/myportfolio.git

git push -u origin main

REPLACE "YOUR_TOKEN_HERE" with the token you copied!

EXAMPLE:
git remote add origin https://ghp_abc123xyz456def789@github.com/babith02/myportfolio.git


═══════════════════════════════════════════════════════════════

METHOD 2: GITHUB CLI (Alternative)
════════════════════════════════════════════════════════════════

STEP 1: Install GitHub CLI
────────────────────────────────────────────────────────────────
Download from: https://cli.github.com/

STEP 2: Authenticate
────────────────────────────────────────────────────────────────
gh auth login

Follow the prompts (choose: GitHub.com → HTTPS → Login with browser)

STEP 3: Push
────────────────────────────────────────────────────────────────
git remote add origin https://github.com/babith02/myportfolio.git
git push -u origin main


═══════════════════════════════════════════════════════════════

WHY NOT GITHUB DESKTOP?
════════════════════════════════════════════════════════════════
You CAN use terminal! GitHub Desktop just makes authentication 
automatic - but if you prefer terminal, use Method 1 or 2 above.


═══════════════════════════════════════════════════════════════

AFTER SUCCESSFUL PUSH:
════════════════════════════════════════════════════════════════
1. Go to: https://github.com/babith02/myportfolio
2. Settings → Pages
3. Source: Select "GitHub Actions"
4. Wait 2-3 minutes

Your site will be live at:
https://babith02.github.io/myportfolio/
